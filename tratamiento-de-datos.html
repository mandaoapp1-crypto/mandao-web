Tratamiento de datos personales

Última actualización: 19 de agosto de 2026.

1. Principios

Mandao procura realizar el tratamiento de datos personales de manera lícita, segura, transparente y limitada a las finalidades informadas al titular.

2. Autorización

Cuando sea necesaria una autorización para el tratamiento de datos personales, esta será solicitada por los canales correspondientes y conforme a la normativa aplicable.

3. Uso de la información

Los datos podrán ser utilizados para atender solicitudes, prestar o habilitar servicios, gestionar comunicaciones, mejorar la experiencia y cumplir obligaciones legales o contractuales.

4. Seguridad

Mandao adopta medidas razonables de carácter técnico y organizativo para proteger la información frente a accesos, usos, modificaciones o divulgaciones no autorizadas.

5. Solicitudes y reclamos

Las solicitudes relacionadas con datos personales pueden enviarse a mandaoapp1@gmail.com, indicando claramente el motivo de la solicitud y los datos necesarios para atenderla.
